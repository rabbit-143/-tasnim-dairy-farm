FUNCTIONS ADDED TO database.js:

1. getDb()
   - Returns: SQLite db or PostgreSQL pool
   - Usage: const db = getDb();

2. getById(table, id)
   - Parameters: table name, record ID
   - Returns: Query result
   - Usage: getById('founders', 1)

3. existsById(table, id)
   - Parameters: table name, record ID
   - Returns: true/false
   - Usage: if (existsById('founders', 1)) { ... }

4. deleteById(table, id)
   - Parameters: table name, record ID
   - Auto-saves SQLite changes
   - Usage: deleteById('founders', 1)

5. save()
   - Persists SQLite database to disk
   - No effect in PostgreSQL mode
   - Usage: save()
