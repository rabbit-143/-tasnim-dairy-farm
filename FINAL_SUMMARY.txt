PROBLEM DIAGNOSIS:
  Route files were importing functions that database.js did not export:
    - getDb() - used in all 6 route files
    - save() - used in all 6 route files  
    - getById() - used in 5 route files
    - existsById() - used in 5 route files
    - deleteById() - used in 5 route files

ROOT CAUSE:
  Functions were defined in db-helper.js but never added to database.js exports

IMPACT:
  - Backend would not start
  - All route files failed to load
  - No API endpoints available
  - Application completely non-functional

================================================================================

SOLUTION IMPLEMENTED:
  
  Added 5 compatibility functions to backend/database.js:
  
  1. getDb() 
     Returns: SQLite db or PostgreSQL pool
     Usage: const db = getDb();
  
  2. getById(table, id)
     Returns: Query result with record data
     Usage: getById('founders', 1)
  
  3. existsById(table, id)
     Returns: true/false
     Usage: if (existsById('founders', 1)) { ... }
  
  4. deleteById(table, id)
     Returns: void
     Auto-saves SQLite data
     Usage: deleteById('founders', 1)
  
  5. save()
     Returns: void
     Persists SQLite database to disk
     Usage: save()
  
  Updated module.exports to include all 5 functions.
