LOCAL DEVELOPMENT STILL WORKS
================================================================================

To develop locally:
  1. Leave DATABASE_URL empty in backend/.env
  2. This auto-uses SQLite (local file)
  3. npm start (backend) + npm run dev (frontend)
  4. Works exactly like before

To use PostgreSQL locally:
  1. Set DATABASE_URL to local PostgreSQL
  2. Schema is compatible (same for dev & prod)

API ENDPOINTS (Reference)
================================================================================

Health Check:
  GET /api/health

Founders:
  GET /api/founders
  GET /api/founders/:id
  POST /api/founders (admin)
  PUT /api/founders/:id (admin)
  DELETE /api/founders/:id (admin)

Blogs:
  GET /api/blogs?featured=true|category=X|limit=10
  GET /api/blogs/:id
  POST /api/blogs (admin)
  PUT /api/blogs/:id (admin)
  DELETE /api/blogs/:id (admin)

Gallery:
  GET /api/gallery?category=X|limit=20
  GET /api/gallery/:id
  POST /api/gallery (admin)
  PUT /api/gallery/:id (admin)
  DELETE /api/gallery/:id (admin)

Careers:
  GET /api/careers?active=true
  GET /api/careers/:id
  POST /api/careers (admin)
  PUT /api/careers/:id (admin)
  DELETE /api/careers/:id (admin)

Settings:
  GET /api/settings
  PUT /api/settings (admin)

Contact:
  GET /api/contact (admin)
  POST /api/contact (public)
  PUT /api/contact/:id (admin)
  DELETE /api/contact/:id (admin)

Upload:
  POST /api/upload/image (multipart/form-data)
