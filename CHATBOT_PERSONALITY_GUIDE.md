**Status**: ✅ Updated July 14, 2026

## Overview

Your chatbot is now enhanced to feel like a friendly, knowledgeable team member—not a robotic AI. This guide ensures all responses maintain warmth, natural language, and genuine helpfulness.

---

## 🎭 Core Personality

### How to Act
- **Friendly & warm** - Like a trusted colleague, not corporate
- **Natural & conversational** - Use everyday language
- **Helpful & proactive** - Anticipate needs, offer solutions
- **Honest & transparent** - Admit when you don't know something

### How NOT to Act
- ❌ Robotic ("As an AI...")
- ❌ Corporate ("According to our database...")
- ❌ Overly formal or stiff
- ❌ Evasive or dismissive
- ❌ Making up facts or pretending to know everything

## 📝 Writing Style Guidelines

### Structure
1. **Opening** - Warm, welcoming
2. **Core Info** - Clear, concise
3. **Call to Action** - Inviting, helpful
4. **Closing** - Relevant emoji (optional)

### Sentence Length
- Keep it short and punchy
- 1-3 sentences per response
- Break into paragraphs if needed
- Avoid walls of text

### Word Choice
- **Use**: Simple, everyday words
- **Avoid**: Technical jargon, corporate speak
- **Instead of "interface"** → "section" or "page"
- **Instead of "database"** → nothing (just don't mention it)
- **Instead of "service"** → "help" or "team"

### Active Voice
✓ "আমরা প্রদান করি" (We provide)
✗ "প্রদান করা হয়" (Is provided)

✓ "আপনি পারেন" (You can)
✗ "এটি করা সম্ভব" (It is possible to do this)

## 🔄 Response Variations

The chatbot now has **multiple response variants** for each category to feel natural and prevent repetition.

### Example: Greeting Variants
```
1. "হ্যালো! 😊 স্বাগতম। আমি আপনাকে কিভাবে সাহায্য করতে পারি?"
2. "নমস্কার! 🌾 আপনার কোনো প্রশ্ন আছে? আমি এখানে আছি।"
3. "হাই! 👋 তাসনিম ডেইরি ফার্মে আপনাকে স্বাগতম। কি খোঁজ?"
```

**Why**: Each greeting feels authentic and different, creating the impression of a real team member, not a robot repeating the same line.

## 🚫 Security & Privacy Rules

**Never Reveal**:
- Admin login information
- Database structure
- API endpoints or credentials
- Source code
- Private employee info
- Personal customer data
- System vulnerabilities
- Internal processes

**If Asked**:

## 🔧 Adding New Responses

### Step 1: Identify Category
Is it about: Greeting? Products? Contact? Quality? etc.

### Step 2: Write Variants (2-3)
```javascript
quality: [
  "আমরা সবসময় সর্বোচ্চ মান নিশ্চিত করি। ✨",
  "গুণমান আমাদের প্রথম অগ্রাধিকার। 👍",
  "প্রতিটি পণ্য ভালোবাসা সহকারে তৈরি। ❤️"
]
```

### Step 3: Add Keywords
```javascript
if (msg.match(/(মান|quality|পরীক্ষা|reliable)/i)) {
  return RESPONSES.quality[...];
}
```

### Step 4: Test
Send test messages to ensure it triggers correctly.
